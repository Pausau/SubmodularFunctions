# Maximizing Submodular Functions

Seminar paper (Seminar: Optimization, H. Schichl, University of Vienna, April 2023) with two
interactive browser demos of the algorithms.

**Read and run it here: https://pausau.github.io/SubmodularFunctions/**

- `MaximizingSubmodularFunctions.pdf` - the paper: approximation guarantees of greedy, thresholding,
  greedy under a matroid constraint, continuous greedy with pipage rounding, and accelerated continuous greedy.
- `cardinality_constraint_demo.html` - greedy and thresholding on a sensor-placement instance.
- `matroid_constraint_demo.html` - the matroid-constrained case.

The demos are single HTML files with no dependencies (tested in Chrome); download one and open it, or use the links above.
